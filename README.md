# 做中学 · 个性化课程生成器

依据教育部《义务教育阶段科学教育"做中学"领航行动指南》（2026 年 8 月印发，2026 年秋季学期起实施），面向 **4-9 年级** 的引导式 PBL 探究课程生成工具。纯前端单页应用，无框架、无构建、无后端依赖。

## 功能

- **7 步引导式流程**：年级方向 → 细分方向 → 课标组合 → 学生提问 → 目标计划（可略过）→ 生成 → 方案
- **六大探究方向**：生命健康、生态环境、地球奥秘、航空航天、新兴产业、人工智能，共 24 个细分方向
- **课标收敛**：按年级课标知识树（656 个节点，1-9 年级 18 学科）穷举命中知识点，支持"本年级基础 + 高一年级拓展"双梯度组合
- **课程图谱**：基于 TeachAny 知识树的 SVG 可视化（主题→学科→知识点，含先修进阶关系与课件标记）
- **学生参与**：引导问题库（24×6）+ 目标计划共创（可略过）
- **AI 个性化**：接入 Cloudflare LLM 网关（DeepSeek-V3.2），以学生问题与计划为驱动生成 4 课时任务链，失败自动回退模板
- **双视图输出**：教师方案（目标/驱动问题/跨学科路径/任务链/评价量表，支持 Markdown/JSON 导出）+ 学生探究记录单（可打印）

## 政策要点

4-9 年级每名学生每学期至少完成 **1 项科学探究任务**（不少于 **4 课时**），遵循"提出问题→设计方案→动手实验→分析改进→分享反思"完整链条，采用纪实性表现性评价。

## 本地运行

```bash
cd 做中学
python3 -m http.server 8000
# 打开 http://localhost:8000
```

或直接双击 `index.html`（除 LLM 增强外的功能均可离线使用）。

## 课标数据再生成

```bash
node scripts/build-curriculum.cjs
# 从 ../teachany-courseware/data/trees/cn/{elementary,middle} 只读抽取
```

## 技术栈

原生 HTML + CSS + JavaScript；课标数据来自 TeachAny 知识树；LLM 经 `https://www.teachany.cn/api/llm/chat/completions`（Cloudflare Pages Function）调用，模型链 DeepSeek-V3.2-exp → Qwen3-Next-80B。
